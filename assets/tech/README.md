# Technology marks

Original source files, downloaded without editing. `sources.json` records each exact URL; `scripts/fetch-tech-logos.mjs` can refresh the local copies. These are third-party trademarks, used only to identify technologies Alexis works with; no affiliation or endorsement is claimed.

- Python: Python Software Foundation, https://www.python.org/community/logos/.
- Odoo: Odoo's own repository, `odoo/odoo`, branch 19.0, `addons/web/static/img/odoo_logo.svg`.
- PostgreSQL: PostgreSQL Global Development Group's official press image, https://www.postgresql.org/about/press/.
- JavaScript: original community mark by Chris Williams / JSConf, https://github.com/voodootikigod/logo.js, MIT. This is a community logo, not a logo issued by ECMAScript's standards body.
- Django: Django Software Foundation, https://www.djangoproject.com/community/logos/.
- Docker: Docker's official brand kit, https://www.docker.com/company/newsroom/media-resources/.
- Git: Git project, https://git-scm.com/community/logos, Creative Commons Attribution 3.0; logo by Jason Long.
- HTML5: W3C HTML5 Logo, https://www.w3.org/html/logo/, Creative Commons Attribution 3.0.
- CSS: CSS-Next Community Group's original mark, https://github.com/CSS-Next/logo.css, CC0 1.0. Represents CSS as a language, not only CSS3.

Logos keep their original geometry, proportions and colors. Placement, opacity, rotation, uniform scale and temporary blur are animation effects; the source files are unchanged.
